# X 浏览器接管（bw）

**根本目的（用户原话，不得改写）**

> **目的**：让 AI 快速高效的用用户手机上那个浏览器，并且当我提出拟人化操作是，可以更拟人化使用浏览器。（并且用完最好能把没用的界面关闭）

据此的三条约束（我的推论，可改）：① 登录态在他的浏览器里 → 不换容器；② 默认求快，拟人是显式开关；③ 收尾只关自己开的界面。

## 命令

```bash
bw fast <URL|词>            # 只读公开页：走 app 内置 WebView，读完 8–10ms；但要等它渲染（本机 1.8s，重站点 30s），不动屏幕、不留标签
bw go   <URL|词> [--new]    # 要登录态、要真点真填：开页并把正文贴回来；默认复用我自己的页，当前页是用户的才新开
bw read [-n 2] [--up]       # 读当前屏；-n = 先翻 N 屏再读；--max N = 正文最多 N 字（默认 3000）
bw tap  <文字> [--nth N]    # 点链接/按钮，回来就是新一屏
bw type <文字> [--into 提示] [--submit]
bw find <词> [--site gov.cn] [-n 2]     # 搜 → 开第 N 条 → 读（默认第 1 条）；本机慢（迁移 §4.9），急就用 go+read
bw tabs                     # 我这次开了什么（读本地记账，0ms，不碰屏幕）
bw tabs 2                   # 切回第 2 个标签：URL 到不了的页面只能这样回去
bw tabs close <标题片段>    # 关一张（带数量护栏，比批量安全）
bw close [--home]           # 收尾：只关我开的 + 复位拟人（默认不回桌面；数量对不上就 exit 3）
bw human [on|off] [--minutes N]  # 拟人：默认 15 分钟（可指定），close 自动复位
bw key back|reload|fwd|home # 四颗键；back 是点错后唯一正确的纠正，home 才回桌面（close 默认不回）
bw tabs clean               # 只关标签、不复位拟人也不清弹窗（close 的轻量版）
bw go --reuse|--fast        # 强制复用我开的页 / 跳过拟人停顿；close --keep-tabs = 只清弹窗+复位拟人
bw shot / bw state          # 节点读不到时截图；开干前一行体检
```

其余开关（`--max`/`--timeout`/`--nth`/`--pause`、`find --fast`）见 `bw -h`。

`bw -q <命令>` 只回结论行（有告警时两行）、不贴正文，用来串多步：`bw -q go X && bw -q tap Y && bw read`。

## 输出怎么读

第一行就是结论：`✔ 做了什么 · 耗时 · 变了没`。**变了就往下走，别再 read 一遍**；只有 `… 没变化` 才需要想。

- 退出码：`0` 成功 / `3` "可能没点对，别接着做" / `2` 硬失败。所以 `a && b` 会自己停在出事那步。
- 首行出现 `⛔ 拦截页` / `⛔ 登录墙` → 这页不是真内容，别读第二遍：换路（`bw go`）或问人。
- `bw fast` 拿回不到 200 字 → 多半是登录墙，改用 `bw go`（两条路 cookie 不互通）。
- 页面标题常被站点写进地址栏；`《?》` 说明有弹窗盖着，先 `bw shot` 看一眼。

## 拟人（bw human on 之后）

做了什么（真机验过）：
- **点击**：真实触摸序列 `tap xy` + 坐标抖动；`tap xy` 两次都不中就**报失败（exit 3）**，不再退回注入式 `tap node`——注入点击没有触摸事件，页面能看出来。
- **打开页面**：走**地址栏**（分段输入 + 停顿 + 真点键盘"前往"），不再是 `intent` 瞬间跳出。所以拟人下 `go` 会慢一些（旧机实测 1.5–2.6s；本机还要多开一次新标签），这是要付的代价。
- **输入**：分段写入，值是逐步变长的（实测写入长度序列 `2,5,8,9,10`）。
- **滚动/后退/刷新**：本来就是真实手势与点底栏按钮。
- **开关**：`bw human on|off [--minutes N]`；`BW_HUMAN=0` 是硬关（连 15 分钟粘性状态也压掉）。

做不到（写清楚，别承诺）：
- **输入不是真按键**。底层是 `ACTION_SET_TEXT` 逐段重写，页面拿到的是多次 set-value，**没有 keydown/keypress 事件**。要"真按键"只能逐字点输入法键盘，候选词/键盘高度/切屏都不可控，不做。
- 所以靠 `isTrusted`/`keydown` 判人的站点仍能识别；细节与边界见 [迁移.md](迁移.md) §六。

## 收尾

**能不新开就不新开**：只读的活走 `bw fast`（内置 WebView，不产生标签）；要走用户浏览器时，`go` 默认**复用我自己开的那一页**（判据：当前标题在记账里），只有当前页是用户的才新开；复用后账本**就地改名**，不会堆旧标题。这样"要关的东西"从源头上就少。

`bw close` 的目标是：关掉本次开的标签、顺手清掉自己惹出的弹窗、复位拟人。**只关自己开的**，"关闭全部"永远不碰。
**默认不回桌面**（`--home` 才回）：本机 Minis 一退到后台，之后再发 VIEW intent 会被系统拦（只能靠新建标签+地址栏），部分机型连拉起都要用户点图标，连续任务会断。

**已启用**（旧机 4 次、本机 2026-11-21 复测通过），判据是"只认自己那张卡消失"：
- 卡片判据：`新建标签` 磁贴 + 标题行同一 y 带靠右 × 小图标 + 左右边界收敛（三档细节与实测值见 [迁移.md](迁移.md) §三）。网页文字几何上和卡片一样，只靠几何会把正文数成卡片。
- 标题严格匹配：`Example Domain` 不会匹到 `Example Domains`（卡片被截断仍算命中）。
- 关一张的判据是**这个标题的匹配数少一张**，不是全屏卡片数少一张（旧机 2026-11-19 就栽在后者，细节见迁移 §二）。
- 点一下没关掉就**立刻停手**，不重试。
- **数量护栏**：关完后面板卡片数必须正好少 `closed` 张；少了更多（疑似误伤）或多了（别人在开标签）→ 判 `changed`，exit 3、不打 ✔、记录保留。
- 应急禁用：`BW_CLOSE_FORCE=0 bw close` → 只核对、不点击。

**没确认落地就不记账、不报成功**：`go` 遇到"页面一字节没变、地址栏又读不到 URL"，宁可 `exit 3` 说"没确认打开"，也不把用户当前页记成自己开的（否则下一次 `close` 会去关人家的页）。VIEW intent 只在 Minis 在前台时送得到（浏览器在前台＝Minis 后台＝系统拦后台启动）。`go` 新开页时会先用 Recents 把 Minis 切回前台再发 intent（约 0.5s，屏幕上会闪一下）；`BW_NO_FRONT=1` 可禁用，改成"新建标签 → 地址栏"。

`bw tabs verify` 是只读核对：`剩 N 个（面板共 M 张卡）`，剩 0 时 exit 0，有剩 exit 3。账本为空时它也会真的去数面板。
已知限制：面板可滚动，只能数到一屏（见迁移 §4.5）。

不在前台时它会说实话（`✘ 没关标签`，退出码 3），别当成成功。
