# 手机操控

## 用户在用时停下来

手机是他的。出现以下任一情况，**先停下来问一句，不要继续点**：

- 键盘弹出 / 输入框有焦点 —— 他在打字
- 连续两次 `ui dump` 的节点明显不同 —— 界面在变，有人在操作
- 两次 `ui info` 之间前台包名变了 —— 他在切 app
- 他说"我在弄""等一下""别动"

不要在用户操作过程中抢焦点、切 app、点屏幕中间、连点。
**做错了不要硬着头皮走完流程** —— 停手、说明、问一句，比把状态搞乱强。

## 四层降级，从上往下走

| 层 | 手段 | 成本 | 何时用 |
|---|---|---|---|
| L0 | intent / deep link / `am start` | ~0 | 有直达入口；需 shell 权限 |
| L1 | `tap node <id>` / `tap text <文本>` | **32–70 ms** | 默认选择 |
| L2 | `tap xy <x> <y>` | 30–70 ms | 节点没 text 或不可点 |
| L3 | `mshot` → 看像素 → tap xy | **1.5–1.9 s** | 自绘/Flutter 界面，节点树是空的 |

**铁律：一次 `ui dump` 拿全量结构，然后一条命令连续执行。绝不"点一下 → 回来看一眼 → 再点"。**
一次模型往返 2–8 s，一次点击 50 ms —— 慢的从来不是点，是看。

## 实测延迟（Android 10 / HONOR Honor 手机 / 1080×2400）

`ui info` 40 ms · `ui dump` 195–343 ms（50–57 节点）· `tap node` 49 ms · `tap text` 130–170 ms · `gesture swipe` 330 ms · `input key` 12–18 ms · 点桌面图标到前台 234 ms。

## 非本机运行

- **只对 Android 10 及以下（SDK ≤ 29）需要这套。** Android 11+ 直接用
  `android-a11y-cli ui screenshot`，不要用 mshot —— 那是绕远路。
- **一次性设置**：把「截屏」磁贴拖到通知栏**第一屏**，下拉即见。
  部分 ROM 把它叫「屏幕截图」「截取屏幕」，届时改 `mshot.py` 里 `tap text` 的参数。
- **下面的延迟数字**来自 HONOR Honor 手机 / 1080×2400 / Android 10 实测。
  换机型只能当参考，用前自己量一遍。

## 截图

本机没有 `ui screenshot`（需 API 30），只能用这条：

```bash
mshot          # → 打印图片路径，约 1.5 s；相册原件自动删除
```

脚本在 `scripts/mshot.py`。它按**文字**「截屏」定位磁贴而不是坐标——磁贴位置你随时可以拖，文字不变。等待时间的来历写在文件头注释里。

## 常用入口库

```bash
mloc learn 微信入口 --desc 更多功能按钮     # 学一个
mloc tap 微信入口                          # 验证 + 点击，39–70ms
mloc list / check / forget
```

库在 `data/locators.json`，跟 skill 一起走。

**该记**：位置固定、语义固定、每次都要点的入口（桌面图标、底部 tab、设置项）。
**不该记**：展开/折叠、提交后消失的按钮——点完界面就变，记了必然 stale。

实测对比：桌面「Minis」图标缓存后连点两次都命中（hits=2 miss=0，54ms / 39ms，
nodeId 从 01po 变成 01r1，但选择器稳定）；而「深度思考」第二次就 stale。

## 验证分级

1. `ui info` 看包名（40 ms，最便宜）
2. `ui dump` 对比节点数/文本集合（350 ms）
3. 都没反应才 `mshot`（1.9 s）

失败一次就换层，别在同一层重试第三次。

## 文件与上下文

- **相册是用户的，不要批量删。** 只允许删 `mshot` 本次刚产生的那一张（按 id）。
  那些截图里混着用户自己截的，删了**不可恢复** —— MediaStore 的 delete 是永久的，
  荣耀图库也没有可用回收站接口。
- 批量删除任何文件前，先列清单让用户确认。
- 截图用完即删（沙箱那份），`shots/` 自动只留最近 5 张。
- 不往 `/usr/local/bin` 之外装东西；脚本只住 skill 的 `scripts/`。
- 新建前先搜现有文件能不能改；能改就不新建。
