# 手机操控（scr）

**根本目的（用户原话，不得改写）**

> 「准确、快速地操控这块屏幕。」

一句话：**看一次、点一次、验一次**。变了就不用再看；没变才需要想。

```bash
scr look                      # 这一屏有什么（节点能读给清单，读不到自动截图）
scr tap 设置                  # 找到→点中→等稳定→把新一屏贴回来
scr type 蓝牙                 # 写进焦点输入框（先 tap 到编辑态）
scr key back                  # back / home / notifications / enter
scr open 哔哩哔哩            # 启动 App（图标 → 文件夹 → 最近任务 → 全页扫）
scr do "open:哔哩哔哩" "tap:动画"   # 一串动作一次做完，中间只回一行
```

脚本 `/var/minis/skills/screen/scr`（软链到 `/usr/local/bin/scr`）。参数与默认值**一律以 `scr <子命令> --help` 为准**，本文不复述数值。

## 命令速查（通用）

| 命令 | 作用 | 关键选项 |
|---|---|---|
| `look` | 读这一屏 | `--shot` 强制截图 |
| `tap <文字>` | 点文字 | `--nth N` 多命中时选第 N 个；`--expect <正则>` 点后断言 |
| `xy <x> <y>` | 点设备像素 | `--scale 2` 只在给截图坐标时用；`--verify` 前后截图比像素 |
| `type <文本>` | 写入输入框 | `--into <文字>` 指定输入框；核对输入框自身文本，不符即 exit 1 |
| `key <键>` | 按键 | back/home/notifications/enter/recents |
| `swipe up\|down\|left\|right` | 滑动 | `--dist`。**参数是手指方向**：`up` = 手指往上推 = 内容往上滚 |
| `open <名字或包名>` | 启动 App | 失败会逐条列出每条路径看到的事实 |
| `wait <文字>` | 等出现 | `--gone` 等消失；`--timeout`。非法正则自动退回字面匹配 |
| `state` | 只报前台和条目数 | 最省的一次"看一眼" |
| `shot` | 截图 | `--full` 额外存一份原图 |
| `do "cmd:参数" …` | 链式执行 | 任一步非 0 即停；**带空格或冒号的参数别塞进 do** |
| `doctor` | 环境体检 | `--save` 把实测值写进 device.json |

桌面专用的 `grid` / `drag` / `drag-into` **不在本文展开**：它们是单一场景（整理桌面），做法与限制见 `scenarios/desktop.md`。

## 手势

日常用 `scr swipe up|down|left|right`，够用就别碰底层。要自己发手势时：

```bash
android-a11y-cli gesture swipe 900 1400 300 1400 --duration 300
android-a11y-cli gesture pinch 640 1386 --scale 0.5
```

拖动（`gesture drag`）是桌面专用，做法与坑见 `scenarios/desktop.md`。

## 怎么读输出

```
app tv.danmaku.bili｜动画｜25 项
s1 C  个人主页 @96,153
s5 C↕ 推荐 @88,273
s6 E  搜索原神 @486,153
s7 ☐  智能充电模式 @936,575
```
`C` 可点 · `E` 输入框 · `☐/✔` 开关 · `↕` 可滚动 · `@x,y` 是**设备像素**。

点的时候直接用文字：`scr tap 推荐`。重名会拒绝执行并列出候选（带 `sN`），用 `--nth 2` 或 `sN` 指定。

结论行按命令各不相同（照抄真实输出，改代码要同步改这里）：
`tap` → `✔ … · 变` / `… · 无变化`；`xy`、`key` → `✔ … · 页面变了` / `… · 页面没动`；
`swipe` → `✔ … · 内容动了` / `… · 注入成功，Nms 内内容未变`。

## 坐标：只有一套

**设备像素**。截图缩到半尺寸，但图上已画好刻度（顶部/左侧红字就是设备像素值），**照红字直接给 `scr xy`，不要再乘 2**。
`--scale 2` 只在你手上有未缩放的截图坐标时才用。

## 四条硬规矩

1. **能用文字点就不用坐标。** 坐标只属于"节点读不到的界面"，给了就用设备像素。
   `sN` 是"上一次 look 的第 N 项"，**屏一变就作废**，过期会被工具直接拒绝（时限见 `--help`），不会瞎点。
2. **文字找不到就停。** 先 `scr swipe down` 回滚或换叫法，别猜着点。
3. **读不到节点先试着截图，不是先放弃。** 只有工具明说 `该窗口禁止截屏`（FLAG_SECURE）才停手交给人。
4. **屏幕顶部 15% 之内不要起手往下滑。** 会被 systemui 当成下拉通知，表现为"什么都没发生"。

## 失败怎么办

1. **先读输出**：`✘` 行说的是事实（找不到 / 有歧义 / 禁止截屏 / 服务没跑），照它分流，别猜。
2. **环境类异常先体检**：`scr doctor`。
3. 维护者视角（回归套件、改代码后怎么验）在 `迁移.md` 第三节，日常操作不用读。

不许：失败就换坐标再试、失败就加 sleep、失败就加断言——那只是把问题推到下一次。

**退出码**（脚本化时按它分流）：

| 码 | 含义 | 该怎么办 |
|---|---|---|
| 0 | 成功（或"未确认"但动作已下发） | 按输出第一行判断 |
| 1 | 查不到 / 未确认 / 超时 | 可换叫法或换目标重试 |
| 2 | 参数或环境不成立（越界坐标、注入失败） | **别重试**，先 `doctor` |
| 3 | 工具主动拒绝（前台不符、起点在顶部死区） | 换位置或换策略，重复同一命令没用 |
| 69 | 无障碍服务没在运行 | 让用户去 设置→无障碍 打开 |

**常见报错**：

| 输出 | 含义 | 下一步 |
|---|---|---|
| `✘ 当前屏 N 项里没有 "X"` | 这一屏确实没有 | 回滚或换叫法 |
| `✘ 无法确定 "X"，命中 N 个` | 文字歧义 | `--nth N` 或 `sN` |
| `✘ 该窗口禁止截屏` | FLAG_SECURE | 停手交给人 |
| `✘ SERVICE_NOT_RUNNING` | 无障碍被关了 | 让用户去开 |
| `? … 未确认` | 判不准（只能看像素） | 用截图定夺，别当成"没动" |

## 该读哪份（路由）

| 你要做的事 | 读 |
|---|---|
| 点按钮、填表、翻页、开 App、看屏幕 | 本文，够了 |
| 读桌面布局（格位/空位/小部件）、移动图标 | `scenarios/desktop.md`（找图标点图标用 `scr look` 就够） |
| 想知道"某条限制怎么来的" | `references/实测记录.md`（关键证据，按结论分组） |
| 换手机、重装、或隔很久回来接着改 | **`迁移.md`**（首次部署注意 / 换机顺序 / 改代码后必做） |
| 改 grid 网格、缩放、前台包名 | `references/设备参数.md` |

## 不做的事

- 不替用户改系统设置（会留下后果的动作先问）。
- 不为了"保险"每步重新确认——工具已经验过了。
- 不在读不到、截不到的界面上盲点坐标。
- 不在用户正在用手机时做手势（切前台会打断注入，还可能让图标落错位置）。
