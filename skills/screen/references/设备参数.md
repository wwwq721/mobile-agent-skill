# 设备参数（device.json）

**何时读**：只在要改网格/缩放/前台包名、或换机后要重测时读；点按类任务不用读。
`device.json` 随机器变，**只有一份权威就是它自己**；本文只解释字段与更新方式，不复制内容。


| 字段 | 含义 | 怎么得到 |
|---|---|---|
| `w`/`h` | 屏幕设备像素 | `scr doctor`（用截图元数据量，不靠猜） |
| `scale` | 截图缩放（半尺寸 = 0.5） | 同上；`xy --scale` 只在给截图坐标时用 |
| `cols`/`rows` | 桌面列/行 | `grid` 逐页核对 |
| `grid_x`/`grid_y` | **普通桌面**每列/每行的格子中心 | `grid` 后用截图逐格核对，偏差 >30px 就重测 |
| `launcher` | 桌面包名 | `scr state` 停在桌面时看前台 |

注意：

- 编辑模式另有坐标系（实测值见 `../scenarios/desktop.md` 第一节），**不要**写进 device.json。
- `note` 里的"旧值"指旧版**普通桌面**格心的等分推算（已废弃），与编辑模式坐标无关。
- 一旦写进错误的尺寸（例如把某次半屏的 1280×2114 落盘），整屏过滤会全错——`scr` 里有 3% 守卫，仍要复核。
- 换机：删掉 `device.json` → `scr doctor --save` 重新量 → 再用 `grid` 核对格子。
