# 关键证据（screen）

> 只看结论用 `../SKILL.md`；桌面操作用 `../scenarios/desktop.md`；部署与改动用 `../迁移.md`。
> 本文只留**支撑现行结论的那几条实测**，一条一段。原话见 `../SKILL.md` 开头。
> 2026-11-22 清理：11-17 的迁移流水账、逐条重测表、旧抖动法细节、已被推翻的"回填论"等一律删除（git 历史里还能查到）。

## 1. 两套坐标，都来自实测

- 普通桌面格心 `188/489/790/1091 × 407/733/1059/1385/1711/2037`（`look` 报出的图标节点中心，列距 301、行距 326），存在 `device.json`。
- 编辑模式格心 `227/502/777/1052 × 560/858/1156/1453/1751/2049`（由拖拽柄节点反推，2026-11-19）。
- 两者差 40–150px，**不可混用**：按编辑模式坐标在普通桌面下点，会落到邻格（曾点开过邻格 ToDesk）。

## 2. 手势时长：时间按路径长度分配；≥5.9s 会被取消

- `gesture path` 的 `--duration` 按**路径几何长度**分配，不是按点数：原地重复同一坐标 = 长度 0 = 不占时间。
- 2026-11-18 探针：三条路径分别 4746ms 成功、5586ms 与 5964ms 均 `path cancelled`。
- 因此代码守卫取 **5200ms**（`scr` 内），文档不另立数字。

## 3. 图标只在刚进编辑模式的 0.5–2s 内暴露

- 普通桌面平时一个图标节点都不给（dump 只有状态栏 + Dock）。
- 进出一次编辑模式后暴露 0.5–2s；窗口一过整页 0 节点（第 3 页连读 6 次都只有"完成/壁纸"）。
- 所以"要看图标"必须先预热（`grid` 与 `mover` 类脚本都这么做）。

## 4. 真按住：本版已原生支持（2026-11-26，1.16-beta.8(46)）

- `gesture drag x1 y1 x2 y2 --hold-ms 800 --duration 800 --end-hold-ms 500` 返回
  `{"segments":3,"holdMs":1300,"totalMs":2100}`，即按下→按住→移动→落点按住，全程不抬手。
- `gesture path "640,300:640,300@600:900,300@1200"` 与 `path --hold-ms 600` 同样生效（回 `holdMs`）。
- 旧版（1.16-beta.5）只能靠"同点重复 + `--interval`"凑时间（20 同点/800ms 在空白处弹出系统编辑菜单），现已不必。

- 20 个完全相同的点 + `--duration 800 --interval 40`，在桌面空白处**弹出系统编辑菜单** → 证明真的按住了 800ms，不是抖动近似。
- 同版本另一处改善：手势进行中 `ui screenshot` 不再被串行化（以前注入期间帧间隔从 0.34s 跳到 5s）。

## 5. 拖拽（2026-11-26 用原生 `gesture drag` 实测）

| 动作 | 结果 | 证据 |
|---|---|---|
| 同页搬一格 | ✅ | 某个 App 5-1→6-3、5-1→6-4、6-4→5-1，`grid` 复读确认 |
| 跨一页 | ✅ | 右边缘悬停 1.5s：p1→p2，落在 p2 6-4 |
| 跨两页 | ✅ | 左边缘悬停 1.6s：p3→p1，落在 p1 5-1 |
| 合并进文件夹 | ✅ 但危险 | 落点压到图标会静默合成新文件夹 |
| 从文件夹拖出 | ✅ | 文件夹视图里把图标拖到 y≈200 松手：文件夹关闭，图标落在桌面 1-4 |
| 拖进文件夹 | ⚠️ 插入位语义 | 落点是"插到该格之前"，文件夹被挤后一格；要合并且得先规范化（源必须在目标之后） |

`scr drag` 已改用原生通道（`--backend drag` 为默认），回包形如
`{"segments":3,"holdMs":1300,"totalMs":2200}`。

## 6. 落点语义与误合成

**插入位语义（2026-11-26，两次实测）**：图标在 1-4、文件夹在 2-1，拖到 2-1 → 2-1 变图标、文件夹到 2-2；
再拖到 2-2 → 2-2 变图标、文件夹到 2-3。页内项数不变，全程不报错。
所以"压中谁就并谁"不成立；合并要求**源在目标之后**（洞在目标之后，回填不跨过目标），否则先把源搬到目标之后的空格。

## 6.5 误合成的实证

第 3 页曾从 12 个图标变成「3 图标 + 4 文件夹」——都是拖动落点压在相邻图标上合成的，全程不报错。

## 7. `continueStroke` 不再需要（本版 `gesture drag` 已覆盖）

2026-11-21 查公开仓库：`OpenMinis/OpenMinis` 分支只有 `main`、`v1.10`–`v1.15`、
`android-1.15-tailscale-fix`；`main` 的 `AccessibilityOffloadHandler.kt`（1267 行）里
搜 `continueStroke` / `willContinue` / `draganddrop` / `motionevent` 全部 0 命中；
最新 release `0-beta-build46`（11-20 05:28）也没有。
**但 2026-11-26 发的 `1.16-beta.8(46)` 已提供 `gesture drag` + `--hold-ms`/`--end-hold-ms`/`@ms`，
等效能力已具备，不必再等 `continueStroke`。**
